## 1. 프로젝트 개요

**SmartStudy**는 고등학생을 위한 목표 맞춤형 공부 루틴 자동 생성 플랫폼입니다.

고등학생은 내신, 모의고사, 수행평가, 비교과 활동 등 다양한 목표를 동시에 준비해야 합니다. 그러나 많은 학생들이 자신에게 맞는 공부 계획을 세우는 데 어려움을 겪고, 계획을 세우더라도 실천 가능성이 낮은 경우가 많습니다.

본 프로젝트는 사용자의 목표, 현재 실력, 학습 성향 등을 입력받아 과목별 공부 비율과 일주일 학습 계획을 자동으로 생성하는 플랫폼을 개발하는 것을 목표로 합니다. 또한 AI를 활용하여 공부법, 시간 분배, 동기부여에 대한 피드백을 제공하고, 선택적으로 학부모가 자녀의 학습 현황을 간단히 열람할 수 있는 기능도 포함합니다.

---

## 2. 프로젝트 목적

SmartStudy의 목적은 공부 계획 수립에 어려움을 겪는 고등학생들이 자신의 목표를 기준으로 현실적이고 효율적인 학습 루틴을 세울 수 있도록 돕는 것입니다.

단순한 일정표 작성 도구가 아니라, 학생의 목표와 현재 실력 간의 차이를 분석하여 우선순위와 시간 배분을 제안하는 자기주도 학습 지원 플랫폼을 지향합니다.

또한 학부모가 자녀의 학습 계획과 진척 상황을 읽기 전용으로 확인할 수 있도록 하여, 학생의 자율성을 해치지 않으면서도 간접적인 학습 지원이 가능하도록 설계합니다.

---

## 3. 주요 기능

### 3.1 목표 입력 기반 루틴 추천

사용자가 설정한 학습 목표와 현재 실력을 비교하여 과목별 우선순위와 시간 배분을 자동으로 계산합니다.

예시 목표:

- 수학 내신 B → A
- 영어 모의고사 2등급 → 1등급
- 수행평가 대비
- 특정 과목 취약 단원 보완

플랫폼은 목표와 현재 상태의 차이를 바탕으로 더 많은 학습 시간이 필요한 과목이나 단원에 높은 가중치를 부여합니다.

---

### 3.2 주간 및 일간 공부 계획 자동 생성

자동 계산된 루틴을 기반으로 주간 및 일간 학습 계획표를 생성합니다.

주요 구성 요소:

- 주간 공부 계획표
- 일간 To-Do 리스트
- 과목별 학습 시간 배분
- 목표별 우선순위 표시
- 사용자가 직접 수정 가능한 일정표

사용자는 자동 생성된 계획을 그대로 사용할 수도 있고, 자신의 일정에 맞게 수정할 수도 있습니다.

---

### 3.3 AI 기반 공부 피드백 기능

GPT API를 활용하여 사용자의 질문에 실시간으로 응답하는 AI 공부 피드백 기능을 구현할 예정입니다.

예시 질문:

- 이번 주에는 어떤 과목에 집중해야 해?
- 수학 내신을 올리려면 어떻게 공부해야 해?
- 영어 모의고사 공부법 추천해줘.
- 오늘 계획을 다 못 끝냈는데 어떻게 조정하면 좋을까?

AI는 사용자의 목표와 학습 계획을 바탕으로 공부법, 시간 분배, 집중력 향상 팁, 동기부여 문장 등을 제공합니다.

---

### 3.4 진행률 확인 및 리마인더 기능

사용자는 각 계획의 이행 여부를 체크할 수 있으며, 이를 바탕으로 학습 진행률을 확인할 수 있습니다.

주요 기능:

- To-Do 완료 체크
- 일간 및 주간 진행률 확인
- 미이행 계획에 대한 리마인더
- 주간 피드백 기반 루틴 수정
- 계획 달성률 시각화

학생이 계획을 실천하지 못한 경우, 단순히 실패로 기록하는 것이 아니라 다음 계획에 반영하여 더 현실적인 루틴으로 조정하는 것을 목표로 합니다.

---

### 3.5 학부모 열람 모드

선택 기능으로 학부모 열람 모드를 제공합니다.

학부모는 학생의 학습 계획과 진척률을 읽기 전용으로 확인할 수 있습니다.

제공 정보 예시:

- 주간 학습 계획
- 과목별 공부 시간
- 전체 진행률
- 완료한 학습 항목
- 미완료 학습 항목

이 기능은 학생의 자기주도성을 유지하면서도 학부모가 간접적으로 학습 상황을 파악할 수 있도록 돕는 것을 목표로 합니다.

## 6. 기대 효과

SmartStudy는 학생들이 막연하게 공부 계획을 세우는 것이 아니라, 자신의 목표와 현재 실력을 기반으로 구체적이고 실천 가능한 루틴을 만들 수 있도록 돕습니다.

기대 효과는 다음과 같습니다.

- 고등학생의 자기주도 학습 능력 향상
- 목표 기반 학습 계획 수립 지원
- 과목별 시간 배분의 효율성 개선
- 계획 실천률 향상
- AI 피드백을 통한 개인 맞춤형 공부법 제공
- 학부모의 간접적인 학습 지원 가능

## 7. 프로젝트 차별성

기존의 플래너 앱은 사용자가 직접 계획을 입력하는 방식이 대부분입니다. 반면 SmartStudy는 사용자의 목표와 현재 실력, 학습 성향을 바탕으로 공부 루틴을 자동 생성한다는 점에서 차별성을 가집니다.

또한 단순한 일정 관리에 그치지 않고, AI 기반 피드백과 주간 루틴 조정 기능을 통해 학생이 자신의 학습 상태를 지속적으로 개선할 수 있도록 설계합니다.

SmartStudy는 다음과 같은 차별점을 가집니다.

- 목표와 현재 실력 간의 격차를 반영한 루틴 생성
- 과목별 우선순위 기반 시간 배분
- GPT API를 활용한 실시간 공부 피드백
- 진행률 기반 루틴 수정
- 학생과 학부모를 함께 고려한 학습 관리 구조
